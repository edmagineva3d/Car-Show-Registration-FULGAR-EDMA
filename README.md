# Car Show Registration System

## Project Description

The Car Show Registration System is a web-based application developed for AutoVista Events – Car Show 2027. It helps manage and monitor car show registrations through a centralized registration dashboard.

## Project Structure

- `backend/` – Contains the C# Web API.
- `frontend/` – Contains the React frontend application.
- `docs/screenshots/` – Contains project screenshots.
- `.gitignore` – Specifies files and folders excluded from Git.
- `README.md` – Contains project information and setup instructions.

## Technologies

### Backend
- C#
- .NET 10
- Entity Framework Core
- SQLite
- FluentValidation
- Scalar

### Frontend
- React JS
- Vite
- Tailwind CSS or Bootstrap
